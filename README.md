# สมุดฝึกงาน

เว็บสำหรับนักศึกษาบันทึกงานรายวัน ให้พี่เลี้ยงรับรองเป็นรอบ และสร้างเอกสาร DOCX/PDF จากข้อมูลที่กรอก ใช้ **React + Vite + Tailwind CSS** สำหรับหน้าเว็บ และ **Go Fiber + SQLite** สำหรับ API และข้อมูล

## เริ่มใช้งานบน Windows

ต้องมี Go 1.25 ขึ้นไป, Node.js 20 ขึ้นไป และ Microsoft Edge หรือ Google Chrome สำหรับสร้าง PDF

```powershell
cd web
npm install
npm run build
cd ..\server
go run .
```

เปิด `http://127.0.0.1:8080` หรือใช้ `start.ps1` หลังจาก build แล้ว ข้อมูลจะอยู่ใน `server/data/internship.db` ซึ่งไม่รวมอยู่ในไฟล์โปรเจกต์

หากใช้ไฟล์ `server/internship-journal.exe` ที่แนบไว้ เปิด `start.ps1` ได้เลยโดยไม่ต้องติดตั้ง Go หรือ Node.js บน Windows เครื่องนี้

## วิธีใช้งาน

1. นักศึกษาสมัครบัญชี กรอกโปรไฟล์ รูป JPG/PNG ที่อยู่และจังหวัด (77 จังหวัด หรือเลือก “อื่น ๆ” แล้วระบุประเทศ) และข้อมูลการฝึกงาน เลือกแผนฝึกงานทั่วไปหรือสหกิจศึกษา กรอกช่วงวันที่และวันหยุดที่ต้องหัก
2. กรอกอีเมลพี่เลี้ยง บันทึก แล้วสร้างลิงก์คำเชิญ นักศึกษาเป็นผู้คัดลอกหรือเปิดอีเมลเพื่อส่งลิงก์ให้พี่เลี้ยง ลิงก์ใช้ได้ 7 วัน หากเปลี่ยนอีเมลก่อนพี่เลี้ยงลงทะเบียน ลิงก์เดิมจะใช้ไม่ได้และต้องสร้างลิงก์ใหม่
3. พี่เลี้ยงเปิดลิงก์และสมัครด้วยอีเมลที่ระบุไว้
4. นักศึกษาบันทึกวันที่ เวลา งานที่ทำ ปัญหา สิ่งที่เรียนรู้ และการมาสาย หรือเปิดเมนูบันทึกรายวันเพื่อนำเข้า CSV หลายวันพร้อมกัน
5. พี่เลี้ยงเปิดเมนู “บันทึกของนักศึกษา” เพื่ออ่านงาน วันที่ เวลา ปัญหา และสิ่งที่เรียนรู้ โดยแก้ไขไม่ได้ จากนั้นเลือกช่วงรายสัปดาห์หรือรายเดือนและพิมพ์ชื่อให้ตรงกับโปรไฟล์เพื่อรับรอง รายการที่รับรองแล้วแก้ไม่ได้
6. แบบประเมินอยู่ในบัญชีพี่เลี้ยงเท่านั้น พี่เลี้ยงให้คะแนน 22 ข้อ บันทึกแบบร่างได้ และพิมพ์ชื่อเพื่อส่งผล นักศึกษาจะเห็นผลและดาวน์โหลดเอกสารได้หลังส่งผลแล้ว
7. นักศึกษาเขียนเนื้อหารายงาน 4 บท เปิด preview เอกสารจากข้อมูลปัจจุบัน แล้วดาวน์โหลดบันทึก แบบประเมินที่ส่งแล้ว และรายงานเป็น DOCX/PDF เมนูรายงานและเอกสารเป็นสิทธิ์นักศึกษาเท่านั้น

มหาวิทยาลัยกำหนดเป็น **มหาวิทยาลัยราชภัฏนครปฐม** รหัสรุ่น **66** รหัสนักศึกษาใช้รูปแบบ **6642590xx** ปีการศึกษา **2569** ภาคเรียนที่ **2** ช่องที่ระบบกำหนดไว้จะแสดงแบบปิดการแก้ไข ส่วนอีเมลพี่เลี้ยงจะปิดการแก้ไขหลังเชื่อมบัญชี บันทึกที่รับรองแล้วมีปุ่มแก้ไข/ลบแบบปิดใช้งาน และแบบประเมินที่ส่งแล้วแก้ไขไม่ได้ API ตรวจสิทธิ์และข้อมูลซ้ำอีกชั้น

ระบบคำนวณชั่วโมงตามแผนจากวันจันทร์–ศุกร์ วันละ 8 ชั่วโมง หักวันหยุดที่นักศึกษาเพิ่มเอง สหกิจศึกษาใช้เกณฑ์อย่างน้อย 80 วันทำงานตามปฏิทิน (16 สัปดาห์ × 5 วัน) และ 540 ชั่วโมงสุทธิ ส่วนฝึกงานทั่วไปใช้ 450 ชั่วโมงสุทธิ ชั่วโมงตามแผนเป็นการประมาณแยกจากชั่วโมงที่บันทึกปฏิบัติงานจริง วันหยุดนักขัตฤกษ์และวันหยุดบริษัทต้องกรอกตามปีและสถานที่ฝึกจริง

Preview บันทึกและรายงานเปิดได้แม้เนื้อหายังไม่ครบ นักศึกษาเปิดดูและดาวน์โหลดแบบประเมินได้หลังพี่เลี้ยงส่งผลแล้ว พี่เลี้ยงกรอกแบบประเมินในหน้าเว็บและดูบันทึกของนักศึกษาได้ แต่ไม่มีสิทธิ์เปิด preview หรือดาวน์โหลดเอกสาร

### นำเข้า CSV

ดาวน์โหลดแม่แบบในหน้า “บันทึกรายวัน” แล้วกรอกคอลัมน์ `date,kind,start_time,end_time,break_minutes,late,work,blockers,learning` บันทึกเป็น UTF-8 โดยวันที่เป็น `YYYY-MM-DD` และ `kind` เป็น `work`, `sick`, `personal` หรือ `holiday` (ใช้ชื่อประเภทภาษาไทยได้) งานประเภท `work` ต้องมีเวลาเริ่ม เวลาสิ้นสุด และรายละเอียดงาน ส่วน `late` ใช้ `true/false` หรือ `1/0` ได้

เลือกไฟล์ขนาดไม่เกิน 2 MB และไม่เกิน 500 แถวเพื่อดูตัวอย่างก่อนนำเข้า วันที่ซ้ำกับบันทึกเดิม วันที่นอกช่วงฝึกงาน และแถวที่กรอกผิดจะแสดงข้อผิดพลาด ต้องแก้ไฟล์ก่อนจึงนำเข้าได้ ระบบบันทึกทั้งไฟล์ในครั้งเดียวและไม่เขียนทับบันทึกที่พี่เลี้ยงรับรองแล้ว

## เอกสาร

- **บันทึกและลงเวลา:** DOCX ใช้ไฟล์แม่แบบของมหาวิทยาลัยที่แนบมาโดยตรง รวมตรามหาวิทยาลัย ช่องรูป และตารางเดิม 23 ตาราง เมื่อบันทึกเกินช่องต้นฉบับ ระบบเพิ่มหน้าที่คัดรูปแบบจากแม่แบบให้อัตโนมัติ ส่วน preview/PDF จัดหน้า A4 ให้ใกล้กับต้นฉบับ มีตารางลงเวลา 23 วันต่อหน้าและตารางบันทึกงาน 7 วันต่อหน้า พร้อมชื่อพี่เลี้ยงที่รับรองตามข้อมูลจริง
- **แบบประเมิน:** DOCX เติมข้อมูลลงในไฟล์แม่แบบที่แนบโดยตรง รวมตารางคะแนน 22 ข้อ ช่องข้อเสนอแนะ และลายเซ็นแบบพิมพ์ชื่อ ส่วน preview/PDF เป็น A4 2 หน้าในลำดับเดียวกัน ส่งออกได้หลังพี่เลี้ยงส่งผลเท่านั้น
- **รายงาน:** DOCX และ PDF มีหน้าปกพร้อมตรามหาวิทยาลัย หน้าข้อมูลนักศึกษาและสถานประกอบการ สารบัญ เนื้อหา 4 บท และภาคผนวกสรุปชั่วโมง ตามโครง PDF ตัวอย่างของอาจารย์ เนื้อหาต้องเขียนและตรวจโดยนักศึกษา

แบบบันทึกและแบบประเมิน DOCX รักษาโครงตารางของไฟล์ต้นฉบับ ส่วน PDF จัดหน้า A4 ให้ใกล้แม่แบบเพื่อเปิดดูในเว็บได้ รายงานอ้างอิง PDF ตัวอย่างซึ่งเป็นรายงานของนักศึกษาอีกคน จึงใช้โครงและรูปแบบหน้าหลักโดยไม่คัดลอกเนื้อหา รูปภาพ หรือจำนวนหน้าของเขา สารบัญรายงานระบุหน้าเริ่มต้นของแต่ละบทตามแม่แบบสั้นนี้ เมื่อเขียนเนื้อหายาวจนเกิดหน้าเพิ่ม ควรตรวจเลขหน้าก่อนส่งจริง

## การพัฒนา

รัน API ที่พอร์ต 8080 แล้วเปิดอีกหน้าต่างเพื่อรัน React dev server:

```powershell
cd web
npm install
npm run dev
```

Vite จะ proxy `/api` ไปที่ `127.0.0.1:8080` ค่าเริ่มต้นของเซิร์ฟเวอร์รับเฉพาะเครื่องนี้ (`127.0.0.1`) **ลิงก์เชิญที่ขึ้นต้นด้วย `http://127.0.0.1` เปิดจากเครื่องพี่เลี้ยงไม่ได้** หากทดสอบบนเครื่องเดียวกัน ให้เปิดลิงก์ในหน้าต่างส่วนตัว หรือออกจากบัญชีนักศึกษาก่อน หากพี่เลี้ยงอยู่คนละเครื่อง ต้องนำเว็บขึ้นโฮสต์บนเซิร์ฟเวอร์ที่มี HTTPS และตั้ง `ADDR`, `APP_SECURE_COOKIE=1`, `DATA_DIR`, `WEB_DIST` ให้เหมาะสม รวมถึงจัดการสำรองข้อมูลและอีเมลจริงก่อนใช้งานระยะยาว

สำหรับ PDF สามารถกำหนด `PDF_BROWSER` เป็น path ของ Edge/Chrome/Chromium ได้ เซิร์ฟเวอร์ใช้ browser แบบ headless เพื่อพิมพ์เอกสาร A4 เป็น PDF

## ขอบเขตเวอร์ชันนี้

ระบบนี้เป็น MVP สำหรับการใช้งานและทดลองในเครื่อง ยังไม่มีการส่งอีเมลอัตโนมัติ ระบบลืมรหัสผ่าน การแก้ไขรายการที่รับรองแล้ว และการจัดการนักศึกษาหลายคนต่อบัญชีพี่เลี้ยงหนึ่งบัญชี ลิงก์คำเชิญมีอายุ 7 วันและผูกกับอีเมลที่ระบุไว้
